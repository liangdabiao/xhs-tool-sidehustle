# xhs-tool-sidehustle 📕

> **程序员副业小红书版 SOP：从小红书搜索生态挖需求，做笔记矩阵或工具引流变现**
>
> 姊妹版 [tool-sidehustle（百度版）](https://github.com/liangdabiao/tool-sidehustle)。百度版找「工具型需求」，本版找「**种草型需求**」——怎么做、求推荐、求教程。

---

## 一、30 秒看懂：这是什么，怎么用（通俗版）

**一句话**：这是装在你项目里的**小红书选品军师**。你跟 AI 说话，它动手从小红书的搜索联想、5118 小红书词库、搜索结果页里，挖出「**用户在搜但没人做好**」的内容赛道，告诉你该做什么笔记、怎么合规涨粉变现。

### 它会带你走的路（7 步）

```
挖需求 → 清垃圾 → 筛机会 → 定赛道 → 做笔记 → 合规转化 → 变现
```

| 步骤 | 通俗解释 | AI 实际干什么 |
|---|---|---|
| 1️⃣ 挖掘 | 小红书用户在搜什么麻烦 | 5118 小红书挖词 + 搜索联想词 + 筛选词标签三路采集 |
| 2️⃣ 清洗 | 废话词扔掉、同类合并 | 「音频裁剪工具/软件/教程」归成一件事 |
| 3️⃣ 筛选 | 找「求而不得」的机会词 | 笔记供给量、头部点赞强度、评论区「求工具」呼声 |
| 4️⃣ 验证 | 赛道值不值得入场 | 内容赛道 12 维度 + 形态选择（账号矩阵 vs 工具站引流） |
| 5️⃣ 做内容 | 笔记怎么写才会火 | 标题埋词/封面规范/互动引导模板 |
| 6️⃣ 转化 | 不违规地把流量变现金 | 评论区引导搜索、私信回复、群聊（严禁外链硬广） |
| 7️⃣ 变现 | 收钱 | 小红书店铺/私信卖工具/群聊付费/蒲公英接广 |

### 怎么用（就 3 步）

**第 1 步：在这个项目文件夹里打开 AI，直接说话**：

- 「帮我在小红书找一批工具类机会词」
- 「『音频裁剪』在小红书的竞争怎么样」
- 「帮我规划一个效率工具账号的内容矩阵」

**第 2 步：它缺账号时会开口要**：5118 登录（挖词用）、小红书登录（联想词和目检用）——都已就绪则全程免打扰。

**第 3 步：拿结果**。产物在项目 `sidehustle-work-xhs/`：机会词 CSV、竞争透视表、赛道结论。

## 二、为什么「小红书版」必须是独立 skill

| 维度 | 百度版 | 小红书版 |
|---|---|---|
| 需求本质 | 工具型：找工具下载 | 种草型：怎么解决、求推荐 |
| 用户语言 | 功能直给 | 场景化口语（人群×场景×痛点×情绪） |
| 筛选信号 | 竞价广告数 | 笔记供给 + 头部强度 + 评论区「求工具」 |
| 引流 | 可放外链 | **严禁外链**，评论区/私信/群聊 |
| 变现 | 会员+广告联盟 | 店铺/私信/群聊/蒲公英 |

## 四、合规红线（写进 skill 的强约束）

1. 禁止伪造互动（自动点赞/关注/评论）——封号风险
2. 导流只用平台允许方式（评论区引导搜索/私信/群聊），不留微信号
3. 抓取克制（间隔≥3s），不绕登录墙，不碰 API 签名
4. 内容基于真实实测，不做虚假种草；敏感赛道直接跳过
