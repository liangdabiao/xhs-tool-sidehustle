# 阶段 3：筛选——找「求而不得」的机会词

百度版筛「竞价红海」，小红书版筛「**内容红海 vs 供给缺口**」。数据：5118 笔记数/流量指数 + 搜索结果页目检（截图视觉读取）。

## 3.1 四条规则

1. **笔记供给过载 → 去掉**：5118 小红书挖词的笔记数超过阈值（默认 5 万，按赛道校准）→ 内容红海，新号难被搜到。
2. **头部过强 → 去掉**：搜索结果页前 10 篇笔记点赞中位数 > 1000 且多为专业号/大号 → 头部垄断，用「机会词清单」记录后绕开。
3. **评论区已有标准答案 → 去掉**：头部笔记评论区已有人给出完整方案/工具名 → 需求已被满足。
4. **「求而不得」信号 → 加权（机会词）**：满足任一即标记 ⭐：
   - 评论区出现「求工具」「求教程」「怎么弄」「蹲一个」「有没有App」等呼声但无人回应
   - 搜索结果以图文碎碎念为主、缺少系统教程（供给质量低）
   - 笔记数少但联想词多（需求在涨、供给没跟上，如「音频裁剪」514 词 vs 少量系统性内容）

## 3.2 目检采样规范

- 每个候选词截图一次搜索结果页（前 9-12 篇），记录：头部点赞、内容形态（图文/视频）、账号类型（素人/专业号）
- 频率 ≥3s/词；截图要求浏览器前台（见 07-automation.md）
- 10-20 词样本足够支撑阶段 4 决策
