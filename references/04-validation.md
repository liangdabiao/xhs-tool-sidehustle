# 阶段 4：内容赛道验证

对机会词做内容赛道评估，与用户确认后进入生产。评估顺序：先定「新鲜度与人群」，再定「形态」。

## 4.1 十二个维度

1. 需求持续性：长期场景 vs 短期热点（热点标 ⚡ 并评估能否沉淀为常青内容）
2. **时代契合度**：AI 化/在线化程度——AI 工具类优先级天然更高（用户心智正在迁移期，供给尚未固化）
3. 内容生产成本：一篇笔记的实测+制作耗时
4. 更新频率要求：赛道要求周更/日更才能维持
5. 供给缺口稳定性：缺口是结构性（工具生态造成）还是暂时性
6. 头部壁垒：现头部账号是否有不可复制资源
7. 平台集中度：分发是否依赖小红书单一平台（联想词 token 通用性意味着可同步抖音——双平台并行加分）
8. 变现距离：笔记到收入隔几步（私信卖工具=1 步；引到站内=多步）
9. 客单价：单次转化价值
10. 矩阵化能力：一个方向能否拆 5-10 个子选题（topics.csv 条数是直接依据）
11. 合规敏感度：医美/理财/医疗/破解类 → 直接跳过
12. 自有资产协同：是否已有工具站/代码可复用（与百度版机会词交叉验证加分）

## 4.2 落地形态判断

- 需求 = 「用一次工具」（转格式/裁音频/生成一次图片）→ **形态 A：工具站 + 引流**
- 需求 = 「持续学习/多工具对比/工作流」→ **形态 B：账号矩阵**
- 拿不准 → 先 B 后 A：账号矩阵成本低，跑出流量反哺工具站决策

## 4.3 竞品调研

- 小红书站内搜赛道词 → 排名靠前账号 → 主页看笔记数/粉丝/橱窗/群聊
- 评论区高频提问 = 选题库补充
- 三方数据平台（新红/蝉妈妈，付费可选，需用户账号）

## 4.4 产出

`04_decision.md`：候选赛道 12 维打分 + 形态选择 + 首批 20 个笔记选题（topics.csv + 评论区提问合并）。
