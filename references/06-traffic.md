# 阶段 6：转化与引流（合规第一）

小红书**严禁站外硬广与外链**。所有转化必须走平台允许路径。违规 = 限流/封号，账号是核心资产。

## 6.1 合规转化路径（按强度排序，从最安全开始）

| 路径 | 做法 | 适用 |
|---|---|---|
| ①评论区搜索引导 | 「我用的 XX，你在小红书搜 XX 就能找到」 | 所有人，最安全 |
| ②私信自动回复 | 粉丝私信 → 关键词回复工具名/使用方法 | 起号后开通 |
| ③群聊沉淀 | 建群聊（群名含赛道词），群公告放工具清单 | 有稳定受众后 |
| ④小红书店铺 | 上架虚拟/实体商品（工具教程、模板、服务） | 需开店资质 |
| ⑤蒲公英接广 | 1000 粉后平台接单 | 账号成熟期 |
| ⑥自有工具站二次转化 | ①②引导用户「去浏览器搜品牌词」→ 工具站会员 | 形态 A |

## 6.2 笔记矩阵打法

- **一个赛道拆 5-10 个功能选题**（来自 02_cleaned/topics.csv），每选题 2-3 篇不同角度
- 主号垂直 + 小号测词：新选题先用小号试水，数据好再上主号
- 关键词层级：核心词（赛道）→ 功能词（单篇）→ 联想词（标题变体），形成站内搜索覆盖网
- 搜索流量特点：一篇命中长尾词的笔记可以持续数月带来搜索曝光（与百度版「标题轮换」同理：数据不好就改写重发）

## 6.3 形态 A 专属：工具站承接

- 笔记只做「教程+场景」，工具本体在站内（浏览器搜品牌词可达）
- 工具站需配置：品牌词 SEO（百度版 skill 联动）、移动端适配（小红书用户手机搜索习惯）
- 转化链路：笔记 → 评论区/私信 → 用户浏览器搜品牌词 → 工具站 → 会员

## 6.4 数据反哺

每月用阶段 3 管线复跑一次机会词：哪些词笔记数涨了（供给跟上了）、哪些评论呼声还在（继续做）、新冒出的联想词（新选题）。`06_traffic/review_<月份>.md`
