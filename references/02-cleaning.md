# 阶段 2：清洗

与百度版（tool-sidehustle）同一套方法与脚本（`scripts/clean_words.py`，共用），本文只列小红书特有差异。

## 2.1 共用规则（详见百度版 02-cleaning.md）

1. 去疑问词（哪里/怎么/多少/好不好…整词去除）
2. 分词 → 去无效词（通用词 + 全局词频 top，**对象词白名单强制保留**）
3. 核心词聚类，同类抽代表；**代表词选最短**（实证：markdown转word在线编辑器=0 条，markdown转word=100 条）

## 2.2 小红书特有差异

**口语归一化（新增）**：联想词 vom 采集回来字符间有空格（音 频 裁 剪 → 音频裁剪），脚本已内置 `re.sub(r"\s+","",w)`；清洗前先归一化。

**疑问词在小红书是「需求信号」不是垃圾**：百度版把「怎么X」当延伸词去掉（因为有基本描述词存在），小红书版**不能全去掉**——「音频怎么截取一部分」这类词本身就是用户的主要表达，且是内容选题的直接来源。处理方式：
- 清洗阶段保留「怎么/求/推荐/教程」类词的**独立簇**（它们是笔记选题池）
- 只去除纯粹的询问废词（哪里下载、多少钱——这类与内容供给无关的）

**新增口语停用词**：绝绝子、yyds、家人们、宝子、码住、蹲、救命、真的、强烈、超好用于归一化后的核心词提取（这些是情绪词，不构成需求核心）。

**新增对象词建议**：剪映、pr、ps、ppt、ipad、华为、小米、微信（平台/工具名是核心词）。

## 2.3 产出

`02_cleaned/representatives.csv`（cluster_key, representative, group_size, members）+ `02_cleaned/topics.csv`（从「怎么/求/教程」簇单独导出的笔记选题池）。
