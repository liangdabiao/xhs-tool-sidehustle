# 阶段 2：清洗与选题池

脚本：`scripts/clean_words.py`（与百度版共用）。目标：把联想短语整理成「代表词簇 + 笔记选题池」。

## 2.1 流程

1. **口语归一化**：vom 采集的短语先 `re.sub(r"\s+","",w)` 去渲染空格（脚本已内置）
2. **去疑问废词**：纯粹与内容供给无关的询问（哪里下载 / 多少钱）整词去除
3. **分词 → 去无效词**：通用词（工具/软件/免费/下载…）∪ 全局词频 top；**对象词白名单强制保留**（图片/音频/水印/剪映/pr/pdf…及 `--extra-objects` 补充）
4. **核心词聚类**：相同核心词簇归一类，代表词选最短

## 2.2 小红书特有处理

**「怎么/求/推荐/教程」类短语是选题资产，全量保留**——它们不参与去疑问词，单独导出为 `02_cleaned/topics.csv`（每条 = 一个现成的笔记选题）。其余词按 2.1 聚类。

**口语停用词表**（核心词提取时去除，属情绪/氛围词）：绝绝子、yyds、家人们、宝子、码住、蹲、救命、真的、强烈、超好用。

**对象词白名单补充**（平台/工具名是核心词）：剪映、pr、ps、ppt、ipad、华为、小米、微信、ocr、ai。

## 2.3 产出

- `02_cleaned/representatives.csv`（cluster_key, representative, group_size, members）
- `02_cleaned/topics.csv`（笔记选题池：phrase, seed_word）
