# 阶段 0：赛道发现——候选工具词从生态数据里来

> 铁律：种子词从数据里来，不从经验里来。工具需求的形态随时代演化，本阶段的目标是**找到词**（发现），需求规模验证留给阶段 1。

## 0.1 生态级种子词（发现轮的输入）

发现轮用的种子词描述的是「**一个需求域**」而非具体工具，让联想词替我们枚举具体工具：

| 需求域 | 生态种子词示例 |
|---|---|
| AI 工具总域 | ai工具 / ai工具推荐 / 免费ai工具 / ai神器 |
| 效率总域 | 效率工具 / 效率神器 / 办公神器 / 学习神器 / 职场工具 |
| 内容创作域 | 自媒体工具 / 剪辑工具 / 做图工具 / 写作工具 |
| 人群域 | 大学生必备工具 / 打工人工具 / 老师工具 |

**同时并行**：小红书站内直接搜「宝藏工具」「神器推荐」，从爆款笔记标题与评论区提取工具名——这是内容生态对需求的直接投票。

## 0.2 采集与提炼

1. 对每个生态种子词跑 `scripts/xhs_suggest.py`（每词 20-35 条真实口语）
2. 对每条联想短语做三分类：
   - **具体工具词**（可独立成需求）：ai抠图 / ai写文案 / 数字人 / 证件照制作 → 进入候选清单
   - **修饰词/筛选词标签**（免费/电脑版/新手/无需会员）：留作阶段 5 标题组合素材
   - **新线索词**（快捷指令 / 手抄报 / 防黑屏 这类意外方向）：进入下一轮发现滚雪球
3. 候选清单去重合并 → 作为阶段 1 的种子词输入

## 0.3 滚雪球迭代

每轮产出必反哺：联想词里出现的新需求域 → 作为新一轮生态种子词再跑。**至少 2 轮**，直到连续一轮没有出现新工具词为止。工作区按 `r1/ r2/…` 保留每轮轨迹。

## 0.4 新鲜度检查

候选清单过一遍时代校验：AI 类/新兴场景词优先标注 ⚡；纯存量本地软件词（转换/压缩类）保留但在阶段 1 单独标记为「存量赛道」，与 AI 赛道分开评估——两类的竞争格局与打法完全不同。
